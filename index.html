04 / SCENES & ENGINE
SCENE GROUP
⌂

主選單與遊戲場景

專案包含 home、01、02，以及圖0 至 圖9 等場景；各場景用途依 Unity 場景設定與觸發器連結。

ENGINE
▧

Unity 2D 專案

專案版本為 Unity 2021.3.20f1；使用 Rigidbody2D、Animator、Collider 與 Unity UI 組成遊戲互動。

使用語言與程式技術

05 / TECHNOLOGY
LANGUAGE
C#

C# 程式語言

遊戲邏輯以 C# 撰寫，使用 MonoBehaviour 腳本掛載在 Unity 遊戲物件上，回應 Update 與碰撞事件。

UNITY API
◈

Unity 遊戲 API

使用 Rigidbody2D、Collider2D、Animator、Input、SceneManager 與 Coroutine，實作移動、碰撞、動畫、輸入和轉場。

UI & DATA
▤

介面與資料

使用 Unity UI、TextMesh Pro、UnityEvent、ScriptableObject 與 PlayerPrefs，處理介面顯示、道具資料及簡單本機狀態。

專案範圍與架構依據
這是一個以 Unity 為核心的遊戲專案。從提供的專案檔案可確認主要程式使用 C#，並有場景、素材、套件設定與遊戲腳本；未見獨立 Web 後端、API 伺服器或資料庫設定，因此本架構圖描述的是遊戲端系統。專案含有多組轉場、位置保存與生命值腳本，實際執行路徑仍以各場景中的元件掛載與 Inspector 設定為準。
